한눈에 보기

회원가입 없이 모든 기능을 쓸 수 있어요. 사진과 필기는 기기 밖으로 나가지 않아요. 결과가 아쉬울 때 직접 알리거나 무료 이용을 신청하며 증빙 사진을 보낼 때만 예외예요. 기기 밖으로 나가는 것은 아래 다섯 가지예요.

  • 제품 개선 통계: 개인을 알아볼 수 없는 월별 합계. 설정에서 끌 수 있어요.
  • 내 필통 기록 로그인 백업 (선택): 직접 로그인했을 때만 계정 번호, 이메일(Google 로그인 때), 내 필통 기록을 보내요.

  • 무료 이용 신청: 공지의 [신청하기]로 직접 보낼 때만 코드를 받을 이메일, 신청 글, 증빙 사진, 앱·기기 정보를 보내요.

  • 보유 기간: 계정을 삭제할 때까지. 계정을 삭제하면 서버의 계정과 기록을 바로 지우고, 별도의 백업 사본을 두지 않아요.

결과 알리기

결과 화면의 '결과가 아쉬우면 알려 주세요'를 누르고 아쉬운 점을 고를 때만 아래 정보를 처리해요. 고르기 전에 사진이 함께 간다는 안내가 보여요.

  • 처리 목적: 알린 결과 문제의 확인, 더 좋은 기능을 만들기 위한 참고(지우기 모델의 평가와 개선).
  • 처리 항목: 고른 이유, 그 장의 원본 사진과 결과 사진, 결과를 낸 설정(모델, 빨간 펜, 편집 여부, 크기, 걸린 시간 등), 앱 버전, 기기 모델, OS 버전, 앱 언어. 이름, 이메일, 계정, 기기·광고 식별자, 위치는 받지 않아요(사진의 위치 정보는 지우고 보내요). 문제집에 이름 같은 글자가 적혀 있으면 사진에 그대로 담겨요.
  • 처리 근거: 이용자가 안내를 보고 직접 보낸 결과 문제를 확인하고 고치는 데 필요한 범위(개인정보 보호법 제15조 제1항 제4호).
  • 처리 경로와 국외 이전: 1:1 문의와 같아요 — Cloudflare(중계), Resend(메일 발송), 개발자의 Gmail(Google LLC), 모두 미국. 중계 서버에는 저장하지 않아요.
  • 보유 기간: 받은 날부터 30일 안에 메일함에서 지우고, 개발자의 컴퓨터로 옮겨 최대 3년 보관한 뒤 지워요. 이미 학습한 모델에는 사진이 남지 않아요.
  • 삭제 요청: 앱의 설정 › 문의하기나 아래 이메일로 알려 주세요. 보낸 날과 기기를 알려 주시면 빨리 찾을 수 있어요. 10일 안에 처리해요.
  • 거부 방법: 알리지 않으면 처리하지 않아요. 앱의 다른 기능은 그대로 쓸 수 있어요.

새 지우개 모델 받기

앱은 열 때 새 지우개 모델이 있는지 확인해요. 이용자가 [받기]를 누르거나 자동 받기를 켰을 때만 모델을 받아요. 받는 것은 모델 파일뿐이고, 이 과정에서 앱은 이용자에 대한 정보를 보내지 않아요.

  • 보내지 않는 것: 사진, 필기 내용, 이름, 계정, 이메일, 기기·광고·설치 식별자, 사용 기록.
  • 통신 정보와 국외 처리: 모델 서버는 Cloudflare, Inc.(미국)의 Cloudflare R2 로 운영해요. 연결할 때 Cloudflare 가 IP 주소, 요청 시각, 앱과 운영체제 버전(User-Agent) 같은 통신 정보를 처리할 수 있어요. 개발자는 접속 기록을 따로 남기지 않아요. 문의: Cloudflare 개인정보 처리방침
  • 나눠 내보내기: 새 모델을 일부 기기부터 내보내려고 앱이 이 기기에서 0~99 사이 숫자 하나를 무작위로 만들어 기기에만 저장해요. 이 숫자는 보내지 않아요.
  • 데이터 사용: 자동 받기는 Wi‑Fi 에서만 해요. 모바일 데이터로는 [받기]를 누를 때만 받고, 그 전에 데이터를 쓴다고 알려 드려요. 자동 받기는 앱의 설정 › 지우개 모델에서 끌 수 있어요.
  • 확인: 받은 모델은 개발자의 서명과 암호화를 확인한 뒤에만 써요. 확인하지 못하면 앱에 든 모델을 그대로 써요.

공지 받기

앱은 열 때마다 공지 목록을 받아요. 받는 것은 공지 글뿐이고, 이 과정에서 앱은 이용자에 대한 정보를 보내지 않아요. 어떤 공지를 보일지는 기기 안에서 App Store·Google Play 나라와 앱 언어로 골라요.

  • 보내지 않는 것: 사진, 필기 내용, 이름, 계정, 이메일, 나라, 언어, 기기·광고·설치 식별자, 사용 기록.
  • 통신 정보와 국외 처리: 공지 서버는 Cloudflare, Inc.(미국)의 Cloudflare Workers 로 운영해요. 연결할 때 Cloudflare 가 IP 주소, 요청 시각 같은 통신 정보를 처리할 수 있어요. 개발자는 접속 기록을 따로 남기지 않아요. 문의: Cloudflare 개인정보 처리방침
  • 닫은 공지: 홈에서 닫은 공지의 이름만 기기에 저장해요. 이 기록은 보내지 않아요.
